# پانسیون (Pansion) — نمونه اولیه رابط کاربری

این پروژه یک نمونه اولیه قابل اجرا از رابط کاربری سامانه مطالعه گروهی «پانسیون» است.

## اجرا
1. فایل ZIP را استخراج کنید.
2. فایل `index.html` را با مرورگر باز کنید.
3. برای دسترسی دوربین، بهتر است پروژه را از طریق localhost اجرا کنید:
   - اگر Python نصب است، در پوشه پروژه اجرا کنید: `python -m http.server 8000`
   - سپس آدرس `http://localhost:8000` را باز کنید.

## امکانات فعال در این نمونه
- داشبورد فارسی و راست‌چین
- تغییر تم روشن و تاریک (با ذخیره انتخاب در مرورگر)
- صفحات گروه‌ها، اتاق مطالعه، چت، گزارش‌ها، پروفایل و تنظیمات
- فیلتر گروه‌ها و ساخت گروه نمایشی
- تایمر مطالعه با شروع، مکث، ادامه و پایان
- درخواست مجوز دوربین و نمایش زنده تصویر دوربین
- ارسال پیام نمایشی در چت محلی

## مواردی که هنوز پیاده‌سازی نشده‌اند
این نسخه، **نمونه اولیه Frontend** است و هنوز Backend یا دیتابیس ندارد:
- ثبت‌نام و ورود واقعی
- همگام‌سازی گروه‌ها و چت بین کاربران
- نقش‌های مدیر کل، مدیر گروه و عضو و مجوزهای امن
- تشخیص خودکار چهره و توقف تایمر بر اساس عدم حضور
- ذخیره ابری جلسات و گزارش‌های واقعی

دوربین در این نسخه فقط پیش‌نمایش محلی دارد؛ هیچ تشخیص چهره‌ای انجام نمی‌شود و تصویر به جایی ارسال یا ذخیره نمی‌شود.

## مسیر توسعه پیشنهادی
1. انتقال UI به Next.js و TypeScript
2. اتصال Supabase Auth و PostgreSQL
3. تعریف Row Level Security برای کاربران، گروه‌ها و پیام‌ها
4. افزودن تشخیص حضور در مرورگر با مدل بینایی ماشین و بدون ذخیره تصویر
5. ثبت رویدادهای حضور/وقفه و محاسبه زمان بر اساس timestamp سمت سرور
6. پیاده‌سازی Realtime برای چت و وضعیت اعضا

## ساختار فایل‌ها
- `index.html`: صفحات و اجزای رابط کاربری
- `style.css`: طراحی واکنش‌گرا و تم‌ها
- `app.js`: تعاملات نمونه، تایمر، دوربین و چت محلی
