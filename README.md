# پانسیون — نسخه ۳

فضای مطالعه‌ی گروهی با زمان‌سنج تمرکز، گروه‌ها و آمار مطالعه. رابط فارسی و راست‌چین، بدون وابستگی (فقط Node).

## اجرا
```bash
npm start        # http://localhost:3000
```
روی Railway: مخزن را متصل کن، Start Command همان `npm start` است و `PORT` را Railway می‌دهد. مسیر سلامت: `/healthz`.

## چه چیزهایی تغییر کرد
- **تم:** حالت روشن / تیره / سیستم + ۵ رنگ اصلی (کهربایی، آبی، سبز، بنفش، گلی). انتخاب ذخیره می‌شود و هنگام لود، قبل از اولین رسم، اعمال می‌شود (بدون فلش).
- **آدرس‌دهی واقعی:** `#/home`، `#/groups`، `#/focus`، `#/stats`، `#/settings` (دکمه‌ی بازگشت و لینک مستقیم کار می‌کند).
- **زمان‌سنج:** هدف ۲۵/۴۵/۶۰ دقیقه یا بدون هدف، حلقه‌ی SVG، مکث/ادامه، ادامه‌ی خودکار بعد از رفرش.
- **جلسه‌ها ذخیره می‌شوند** و آمار واقعی می‌سازند: امروز، کل، میانگین، روزهای پیاپی، نمودار ۷ روز.
- **گروه‌ها:** ساخت (با اعتبارسنجی و جلوگیری از نام تکراری) و حذف دومرحله‌ای.
- **تنظیمات:** پشتیبان‌گیری JSON و پاک‌کردن داده‌ها.
- **رفع باگ‌ها:** حالت خالی بعد از ساخت گروه پنهان نمی‌شد؛ خطای `localStorage` کل برنامه را از کار می‌انداخت؛ شمارنده‌های آمار هیچ‌وقت به‌روز نمی‌شدند.
- **دسترس‌پذیری:** `<dialog>` بومی (Esc، فوکوس)، `aria-current`، منوی موبایل با overlay و Esc، حلقه‌ی فوکوس، `prefers-reduced-motion`، کنتراست ≥ ۴٫۵:۱ در همه‌ی ترکیب‌های تم.
- **فونت Vazirmatn داخل پروژه است** (`public/fonts`)؛ دیگر به Google Fonts وابسته نیست.
- **سرور:** فقط پوشه‌ی `public/` سرو می‌شود (`server.js` و `package.json` دیگر عمومی نیستند)، چک مسیر درست، gzip، ETag، هدرهای امنیتی و CSP سخت‌گیرانه.

## ساختار
```
server.js            سرور استاتیک
public/index.html    صفحه‌ها
public/style.css     توکن‌های تم و طراحی
public/app.js        منطق برنامه
public/theme-init.js اعمال تم قبل از رسم
public/fonts/        Vazirmatn
```

## محدودیت‌ها
هنوز بک‌اند، ثبت‌نام، دیتابیس و همگام‌سازی بین کاربران ندارد؛ همه‌ی داده‌ها فقط در همین مرورگر است. چت، حضور زنده و تشخیص حضور پیاده‌سازی نشده‌اند.
