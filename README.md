# پانسیون — بازطراحی مینیمال نسخه Railway

## اجرا روی Railway
1. محتوای این پوشه را در ریشه GitHub repository قرار بده.
2. در Railway از مسیر New Project → Deploy from GitHub Repo مخزن را متصل کن.
3. Start Command را `npm start` قرار بده (معمولاً از package.json تشخیص داده می‌شود).
4. از Settings → Networking یک دامنه بساز.

## Variables
برای اجرای این نسخه هیچ Environment Variable اجباری لازم نیست. Railway مقدار `PORT` را در زمان اجرا فراهم می‌کند.

## آنچه در این نسخه واقعاً کار می‌کند
- رابط فارسی و راست‌چین با طراحی واکنش‌گرا
- انتخاب تم روشن، تیره و سیستم، با ذخیره انتخاب در مرورگر
- زمان‌سنج محلی شروع/مکث/پایان
- ساخت گروه با نام و نوع دسترسی، ذخیره فقط در مرورگر فعلی
- صفحه‌های خالی برای گروه‌ها و آمار، بدون کاربر، پیام، گروه یا نمودار ساختگی

## محدودیت‌ها، شفاف و مهم
- این نسخه هنوز Backend، ثبت‌نام/ورود، دیتابیس یا همگام‌سازی بین کاربران ندارد.
- گروه‌هایی که می‌سازی فقط در همان مرورگر ذخیره می‌شوند؛ «عمومی» فعلاً عمومی واقعی نیست.
- جلسه‌ها پس از پایان در پایگاه داده ثبت نمی‌شوند و آمار تاریخی واقعی وجود ندارد.
- چت گروهی، دوربین و تشخیص حضور/چهره در این نسخه پیاده‌سازی نشده‌اند؛ دوربین نیز بدون درخواست تو فعال نمی‌شود.
- برای نسخه چندکاربره باید Backend و دیتابیس (مثلاً Supabase) و مجوزهای دسترسی پیاده‌سازی شوند. تشخیص حضور، در صورت افزودن، باید با رضایت روشن کاربر و پردازش محلی تصویر انجام شود.

## ساختار
- `index.html` رابط و صفحات
- `style.css` تم و طراحی واکنش‌گرا
- `app.js` تعاملات محلی
- `server.js` سرور استاتیک سازگار با Railway
